# Instruções deste projeto

- Antes de alterar o site ou responder sobre o plano de evolução, leia `MELHORIAS_PENDENTES.md`.
- Registre novas ideias do usuário nesse arquivo. Mantenha cada estado fiel ao que foi implementado, testado e publicado.
- Ao concluir uma melhoria, atualize a lista. Em toda resposta futura sobre o projeto, mencione brevemente o que continua pendente ou forneça um link para a lista atualizada. Se o usuário pedir apenas para guardar uma ideia para depois, registre-a sem implementá-la.
- Preserve o arquivo original `ESPECIFICACAO_SITE_NAVE_ESPACIAL.md`, que fica fora do repositório.
